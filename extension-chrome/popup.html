Tab Transfer

Chrome → Firefox

To send tabs from Chrome to Firefox, Tab Transfer needs a small helper app on your computer.

Download installer

Windows 10/11 · 64-bit · no admin rights needed

Setup

  1. Run TabTransferSetup.exe.
  2. If Windows shows a warning, click More info → Run anyway.
  3. Press Alt+Shift+S or right-click a page → Send to Firefox.
Why the warning? The installer isn't code-signed yet, so Windows treats it as coming from an unknown publisher. The helper is open source and only opens links in the other browser. You're welcome to read the code on GitHub before installing, or build it yourself.
Remove anytime from Settings → Apps.
