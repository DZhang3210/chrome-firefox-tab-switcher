Tab Ferry is installed

Firefox → Chrome

Two quick steps and you can send any tab or link from Firefox to Chrome. The Tab Ferry icon is on your toolbar. Click it any time to check that everything is working.

1 Install the helper app

Firefox can't open Chrome by itself, so Tab Ferry uses a small helper app on your computer.

Checking for the helper app…

Download the helper app

Windows 10/11 · no admin rights needed

Open the downloaded TabFerrySetup.exe. If Windows says "Windows protected your PC", click More info → Run anyway. The helper is open source and only opens links in the other browser.

2 Send a tab

Right-click anywhere on a page, or on a tab → Send to Chrome. The page opens in Chrome and closes here.

Right-click a link → Open link in chrome to open just that link.

You can close this tab now. To remove Tab Ferry later, click its icon → Uninstall helper app.
